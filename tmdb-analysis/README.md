# TMDB Movie Data Analysis
This project is a data analysis project centered around analysing movie data fetched from The Movie Database (TMDB). It includes modular codes for API data extraction, data cleaning and transformation, KPI analysis, for visualization with selected movie IDS.

## PROJECT OBJECTIVES
Extract complete data from TMDB API using a list of selected movie IDs
Clean and transform data into a format ready for analysis
Perform analysis and KPI implementations such as:
- Highest / Lowest Profit
- Profit and ROI analysis
- Most popular, Most voted, Highest rated, Lowest rated movies, etc.
- Perform data visualization on cleaned data 

## HOW TO RUN THIS PROJECT
1. Clone the repo
2. Install dependencies
3. Insert your generated TMDB API key

## DATA SOURCE
All movie  data was extracted from (THE MOVIE DATABASE) TMDB (https://developer.themoviedb.org/docs) using a list of preselected movie IDs.
